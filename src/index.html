Build Stylescape with Parcel

You've successfully loaded the Stylescape + Parcel example! This project demonstrates how to integrate Stylescape with Parcel bundler to compile and bundle Sass and JavaScript.

Features

  • Parcel bundler with zero configuration
  • Sass compilation via @parcel/transformer-sass
  • Stylescape components and utilities
  • Hot module replacement for development

Accordion Example

What is Stylescape?

Stylescape is a modern CSS framework that provides a comprehensive set of components, utilities, and design tokens for building beautiful web interfaces.

Why use Parcel?

Parcel is a zero-configuration web application bundler that automatically handles Sass compilation, JavaScript bundling, and asset optimization out of the box.

How to get started?

Simply run npm install to install dependencies, then npm start to launch the development server with hot reloading.
